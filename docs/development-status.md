## 复现本机检查

在工程根目录运行：

```powershell
npm install
npm test
npm run test:db
npm run build
npm run preview
```

构建预览通常使用 `http://127.0.0.1:4173`，地址以终端显示为准。边修改边预览可使用 `npm run dev`，通常是 5173 端口。PowerShell 如果阻止 `npm.ps1`，把命令中的 `npm` 改为 `npm.cmd`。

浏览器检查顺序为：首页进入办事指南，搜索、查看详情并返回；进入美食，切换校内外、搜索和筛选、查看详情并返回；进入发布页面，检查必填项、价格、首次星级、图片预览与移除、相似菜品提示和失败后的表单保留。空配置下提交应明确提示没有保存，返回列表后不能凭空出现刚填写的菜品。

Chrome 或 Edge 的设备预览可以设置为 390 × 844，并补查 320、780 和 1280 像素宽度，观察横向滚动、文字重叠和按钮尺寸。设备预览结果只能说明相应浏览器尺寸下的布局，不能证明实际手机体验。

数据库检查的具体范围和后续真实服务清单见 [Supabase 配置与测试说明](../supabase/README.md)。原始需求见 [项目说明书](project-requirements-v0.3.md)。
