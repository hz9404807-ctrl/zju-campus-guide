## 可以实施的三条路线

1. **官方入口导航**：真实对话地址已验证，可在教务类页面提供外部入口，学校登录由每位用户完成。网站代码本轮未更改；导航不等于站内API接入。
2. **官方嵌入窗口或Web SDK**：真实对话页当前受SAMEORIGIN限制。需要学校另行提供正式的分享地址/SDK、允许的站点域名、登录方式和授权条款。验证手机布局、身份认证是否被第三方Cookie限制、超时及返回本站的路径。不要绕过官方`frame-ancestors`或`X-Frame-Options`。
3. **官方智能体API**：拿到专用接口、鉴权及现成智能体权限后，新增服务端代理与前端对话面板。现有React/TypeScript及Supabase适合作为实现基础；目前仓库只有数据库迁移，没有已部署的AI代理函数。

API路线预期结构：浏览器 → 本站后台 → 学校授权的浙小本接口 → 本站显示回答。密钥仅保存在服务端环境；参见[Supabase Edge Functions密钥文档](https://supabase.com/docs/guides/functions/secrets)。申请表明确要求调用服务器IP，未登记IP不能调用API。需要先确认校外服务端是否获准及出口IP方案；不能直接假定Supabase的出口满足该要求。若仅开放校园网，需要学校认可的网关或校内部署。Supabase匿名身份不等于浙大通行证身份。

### 通用API标准申请实际缺项

- 创建应用表：申请人手机、邮箱、办公电话；所属单位；单位负责人及其手机、邮箱、办公电话。真实单位与负责人由用户或课程老师确认。
- 下载并填写[浙江大学应用系统接入管理规范](https://appcloud.zju.edu.cn/static/doc/%E6%B5%99%E6%B1%9F%E5%A4%A7%E5%AD%A6%E5%BA%94%E7%94%A8%E7%B3%BB%E7%BB%9F%E6%8E%A5%E5%85%A5%E7%AE%A1%E7%90%86%E8%A7%84%E8%8C%83.rar)，取得要求的签字、公章及扫描附件。表单接受word/pdf，最多5个附件，每份10MB。
- 应用名称、开发商名称、开发语言、网址、端口、部署环境及功能描述。网址栏最多32字符，当前较长的演示域名需要向平台确认可接受的填写方式，不能静默截断。表单提示HTTPS 443按80填写，其它端口按实际填写，以正式表单要求为准。
- 调用服务器IP：需要真实且获准的服务器出口IP。没有公网固定出口方案，暂不能承诺直接用Supabase代理通过白名单。
- 应用获批后再选接口、填写用途与调用量，经信息技术中心、院级领导及接口管理员审批。一般模型授权不会自动提供浙小本知识库及专用会话接口。
