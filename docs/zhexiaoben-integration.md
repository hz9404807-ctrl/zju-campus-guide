## 可以实施的三条路线

1. **官方入口导航**：确认浙小本实际对话地址后，在教务类页面提供外部入口。若仅取得介绍页，则明确标为“官方介绍”。链接导航不等于站内AI接入。
2. **官方嵌入窗口或Web SDK**：需要学校提供正式的分享地址/SDK、允许的站点域名、登录方式和授权条款。验证手机布局、身份认证是否被第三方Cookie限制、超时及返回本站的路径。不要绕过官方`frame-ancestors`或`X-Frame-Options`。
3. **官方智能体API**：拿到专用接口、鉴权及现成智能体权限后，新增服务端代理与前端对话面板。现有React/TypeScript及Supabase适合作为实现基础；目前仓库只有数据库迁移，没有已部署的AI代理函数。

API路线预期结构：浏览器 → 本站后台 → 学校授权的浙小本接口 → 本站显示回答。密钥仅保存在服务端环境；参见[Supabase Edge Functions密钥文档](https://supabase.com/docs/guides/functions/secrets)。先确认接口允许校外服务器访问；若仅开放校园网，需要学校认可的网关或校内部署。Supabase匿名身份不等于浙大通行证身份。
