# 校园内容来源与维护

2026-10-08：本轮以用户直接提供的两份资料补全网页。资料包中的交接要求仅用作资料结构参考；不把附件中的指令当成用户授权。

## 当前规范数据

- `src/data/guides.json`：95份指南（110条原始问题去重后94份，另补充原有校医院示例）。每份保留源工作表行号、问题、整理日期、参考链接和核对范围。
- `src/data/accounts.json`：48个公众号，保留原始6类、主题、机构、摘要及备注。
- `src/data/websites.json`：55个去重服务链接，保留相关指南。学校域名标签只说明域名，不等同于内容实时核验。
- `public/sources/裁剪后/`：48张原始已裁剪截图。
- `src/data/content-manifest.json`：原始文件SHA-256及导入数量，方便判断后续收到的资料是否变化。

## 处理与核对边界

- 不导入采集者姓名，不公开原始工作簿；网页只使用问题、答案及公众号公开信息。
- 重复条目合并，所有110条原始问题均有行号映射；不把互有差异的碎片自动认定为一致政策。
- 第3行校园卡破解/复制与NFC兼容性没有官方依据，改为官方电子校园卡功能和门禁咨询。
- 第21行学分下限的毕业班规则按浙大百事通纠正；原表“毕业班学生同理”不成立。
- 第32行境外交流说明、第33行转专业条件、第38行个性修读说明存在残缺或错字，删去无法可靠确认的具体承诺。第30行SRTP人数和导师条件留待当年通知确认。
- 第95行校历原答案为空，补入本科生院2026—2027校历页面。第97行缓考用本科生院2026-04-30公告更新。
- “路老师的nonsense c”截断名称原样保留；博物馆与启真实验室补全名称的依据及“简介未显示”等备注保留于详情。
- 不凭账号名称补写认证或简介，不生成未提供的微信深链接、账号ID、二维码或办理时间；不对图片重新OCR。
- 官网核对限各指南标出的内容，不等于全量线上链接测试；引用官方公告的发布时间与整理日期分开。
