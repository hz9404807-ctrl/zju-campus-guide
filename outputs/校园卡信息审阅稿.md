# 校园卡信息审阅稿

本稿覆盖网站现有的7条校园卡指南，供你确认内容写法。正文以完成事项为目标，开头概括整体流程，解释融入操作，结尾提供官方参考网页。尚未接入网页；内部核对记录与正文分开保存。

## 1. 校园卡丢了，怎么挂失和补办？

**整体流程：在校园卡App中挂失遗失卡，带好材料到校园卡服务窗口补卡，领到新卡后核对信息和使用状态；如果补卡前找回旧卡，转到本稿第5项办理恢复使用。**

### 办理前准备

- App办理：需要能够登录本人的“浙大校园卡”账号。
- 本人到窗口补卡：带本人身份证原件。
- 委托他人到窗口补卡：准备持卡人身份证复印件、持卡人本人签字的委托书，以及代办人身份证原件和复印件。

### 具体操作

1. 打开“浙大校园卡”App，进入底部的【应用】，打开【挂失·解挂】服务，选择挂失并确认。挂失会暂停卡片及账户使用，用于阻止遗失卡继续被使用，不等于已经补好新卡。
2. 操作后查看返回提示和卡片状态，确认挂失已完成。如果没有成功提示或入口找不到，带本人身份证到下表中的校园卡服务窗口，向工作人员说明“校园卡遗失，需要挂失并补卡”。
3. **窗口补卡：**将上述本人或代办材料交给工作人员，申请补卡。办理前向工作人员确认所需费用和付款方式。
4. 领取新卡后核对姓名等信息，并确认卡片已可使用。补卡后刷不了热水，可把新卡带到校园卡自助一体机、食堂白色POS机或校园卡服务窗口做卡片校正；仍未恢复可拨打0571-88208849。

### 遇到问题怎么办

- App无法登录或无法完成挂失：直接到服务窗口办理，不必先找回旧卡。
- 补卡前找到旧卡：按第5项操作恢复使用。如果已经领到新卡后又找到旧卡，先让服务窗口核对旧卡状态，不自行恢复旧卡。
- 新卡门禁异常：先核对卡片是否仍被挂失或冻结；卡片信息同步超过24小时仍不能用时，到对应门禁管理单位办理，例如宿管或图书馆。

**官方参考：**[校园卡服务说明](https://itc.zju.edu.cn/xykwgr/list.htm)。

## 2. 怎样用手机上的电子校园卡消费和认证？

**整体流程：登录浙大钉，打开电子校园卡，在支持二维码的消费或认证设备前出示电子码；消费后检查账单，不能扫码的设备按现场支持方式使用实体卡。**

### 办理前准备

手机能够登录浙大钉并显示本人的电子校园卡；消费前先确认校园卡余额足够。

### 具体操作

1. 打开浙大钉并登录，进入底部【工作台】，选择【电子校园卡】。
2. 在支持扫码支付的食堂、超市等场所，打开付款码并向收款设备出示，等待交易结果。
3. 支付后查看消费账单，核对金额和是否扣款。
4. 需要身份认证时，在支持电子校园卡二维码的设备上出示电子码。宿舍门禁、图书馆等是否支持电子码取决于对应设备与授权，不能把“手机有电子校园卡”当作所有刷卡设备都能使用的保证。

### 遇到问题怎么办

电子码显示正常但某处认证失败时，向该处管理人员说明“电子校园卡在这里无法认证”，请其检查设备支持方式和卡片权限。卡片显示被冻结或被挂失时，先到校园卡服务窗口处理卡片状态。

**官方参考：**[信息技术中心电子校园卡说明](https://itc.zju.edu.cn/xykwgr/list.htm)。

## 3. 校园卡余额不足，怎样开通自动充值？

**整体流程：先核对校园卡是否已绑定可用的银行卡，再到校园卡服务窗口申请自动转账，确定触发余额和每次转入金额，确认开通后按设定使用。**

### 办理前准备

准备校园卡及拟用于转账的银行卡信息，并想好希望在余额低到多少时充值、每次充值多少。出发前拨打下表中本校区窗口电话，问“开通校园卡自动转账需要带哪些材料、是否需要先到银行绑定”。

### 具体操作

1. 让校园卡服务窗口核对校园卡与银行卡是否已经建立转账关系；如果尚未绑定，按窗口确认的银行办理方式完成绑定后，再继续开通。
2. 到校园卡服务窗口提出“开通校园卡自动转账”的申请。
3. 确定两项设置：余额低到多少时触发充值，以及每次从银行卡转入多少。按自己的消费需要与工作人员确定这两项金额。
4. 办完后请工作人员确认自动转账已开通，并记下这两项设置。确认绑定的银行卡中有足够余额。

### 遇到问题怎么办

- 更换或补办银行卡后不再自动转账：先到银行核对新银行卡与校园卡的关联，再联系校园卡服务窗口检查。
- 急需使用但自动转账未完成：先按第6项选择手动充值；保留银行扣款及校园卡账单信息，向窗口核对异常。

**官方参考：**[后勤集团自动转账办理说明](https://zulg.zju.edu.cn/info/1203/8336.htm)。

## 4. 校园功能卡怎样申请并开始使用？

**整体流程：先由所在学院或单位办理人员信息注册与审核，开通校园卡账户后再登录App使用电子卡；需要实体卡的单位自招工作人员，可带身份证到校园卡服务窗口领取办理。**

### 适用情况与准备

- 本项面向单位自招工作人员、进修及其他需要功能卡的人员。
- 全日制学生的首张校园卡通常由学校统一制作、学院发放，不要套用单位自招人员申请流程。
- 准备本人身份及所在单位信息；单位自招工作人员需要实体卡时，准备身份证原件。

### 具体操作

1. **单位自招工作人员：**到所在单位办公室，向负责人员注册审核的管理员提出“申请校园功能卡”。请管理员告知本身份适用的注册入口和所需资料，按要求登记信息，再由单位完成审核。
2. **进修及相关学生：**联系所在学院负责办卡的老师，由学院报送制卡信息或名单，完成办卡后按学院通知领取，不套用工作人员的个人注册入口。
3. 单位确认校园卡账户已开通后，登录“浙大校园卡”App，完成身份认证，充值并打开付款码使用。
4. 单位自招工作人员需要实体卡时，携身份证原件到校园卡服务窗口，说明账户已经开通，请工作人员核对本人信息并办理实体卡。

### 遇到问题怎么办

- App显示用户不存在：先请单位办卡管理员确认注册审核和账户生成是否完成，再联系校园卡服务窗口核对。
- 单位要求使用指定注册入口：请单位管理员确认入口适用于本人的身份，再按其要求填写资料并提交审核。

**官方参考：**[后勤集团功能卡办理说明](https://zulg.zju.edu.cn/info/1203/8336.htm)。

## 5. 挂失后找回校园卡，怎样恢复使用？

**整体流程：确认找回的是自己的卡且尚未补办新卡，再在校园卡App中办理解挂，核对操作结果；无法在线完成时，到服务窗口恢复卡片使用。**

### 办理前准备

准备找回的本人校园卡及能够登录的校园卡App。需要线下核对时，建议带身份证和找回的卡，方便工作人员核对。

### 具体操作

1. 打开“浙大校园卡”App，进入【应用】中的【挂失·解挂】服务。
2. 选择解挂操作并确认。这里的操作是恢复已挂失卡的使用。
3. 查看操作结果与卡片状态；没有完成提示时，不把返回首页当作恢复成功。
4. App入口不适用或操作失败时，把身份证及找回的卡带到下表中的校园卡服务窗口，说明“卡已经挂失，现在找到了，需要恢复使用”，请工作人员核对并处理。

### 遇到问题怎么办

已经补办新卡后又找到旧卡时，先由服务窗口确认应使用哪张卡及旧卡如何处理，不继续执行本稿的在线恢复路线。恢复后只有某个门禁不能用时，让该门禁管理单位检查权限。

**官方参考：**[后勤集团挂失与解挂操作说明](https://zulg.zju.edu.cn/info/1203/8336.htm)。

## 6. 校园卡怎样充值，付款后怎么确认到账？

**整体流程：选择浙大钉、校园卡App、支付宝或线下窗口充值，核对学校和本人信息后付款，再检查校园卡余额或账单；已扣款未到账时，保留记录到服务窗口核查。**

### 办理前准备

准备能够登录的对应App，以及用于付款的支付宝或已绑定银行卡；线下现金充值需前往校园卡服务窗口。

### 具体操作

选择一种方式完成充值，不必把以下方式全部操作一遍：

- **浙大钉：**登录后进入【工作台】→【电子校园卡】→【充值】，按页面填写充值金额并完成付款。
- **浙大校园卡App：**登录后进入【首页】→【卡片充值】，选择支付宝或绑定银行卡转账，核对金额后完成付款。
- **支付宝：**首页搜索【支付宝校园卡】→【一键充值】→选择学校【浙江大学】→填写页面要求的信息→提交并付款。
- **现金：**到校园卡服务窗口，向工作人员提出现金充值，并核对充值对象和金额。

付款完成后检查校园卡余额或充值账单是否增加，核对金额。付款平台显示付款成功，不应直接代替校园卡到账确认。

### 遇到问题怎么办

- 银行或支付宝已经扣款、校园卡未显示充值：保留支付订单及校园卡账单，联系本校区窗口核查。高峰时段可能存在到账延时；查询时同时说明充值时间、金额及支付方式。
- 银行转账提示未建立委托关系：到校园卡服务窗口核对绑定情况；更换过银行卡的，先到银行核对关联。

**官方参考：**[信息技术中心校园卡充值说明](https://itc.zju.edu.cn/xykwgr/list.htm)。

## 7. 校园卡怎样销户，余额怎么处理？

**整体流程：携本人有效身份证件到校园卡服务窗口提出注销，核对卡片账户及余额处理安排，确认注销完成；注销后的原账户不能恢复。**

### 办理前准备

本人有效身份证件。建议同时带校园卡和能查看余额的App，方便核对。

### 具体操作

1. 到下表中的校园卡服务窗口，向工作人员提出校园卡注销申请，出示本人有效身份证件。
2. 核对注销的是本人的校园卡账户，并确认是否仍需使用该卡；不要把余额不足或卡片丢失当成需要注销的理由。
3. 如有剩余余额，在办理时请工作人员确认退款金额、退回方式及后续是否需要领取或查询。卡种与离校情况会影响余额处理方式，办理时一并说明自己的身份和离校情况。
4. 办完后当场确认账户已经注销，以及余额处理安排是否办妥。原账户注销后不可恢复。

### 遇到问题怎么办

如果只是毕业离校、账户有效期变化或需要保留消费功能，办理前先向服务窗口说明具体情况，再确认是否注销。金额或退款安排有疑问时，当场让窗口核对，不只看App能否登录。

**官方参考：**[信息技术中心校园卡注销说明](https://itc.zju.edu.cn/xykwgr/list.htm)。
